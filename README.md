# IPRC1000 Adapter for macOS

![IPRC1000 Adapter](docs/images/overview.jpg)

把 IPRC1000 蓝牙遥控器变成 Mac 的自定义快捷键和语音输入设备。按键可映射为单键、组合键或媒体键；按住麦克风说话，文字输入当前光标处。

## 下载与依赖

从 [GitHub Releases](https://github.com/wangchll/IPRC1000/releases/latest) 下载 **v0.3.2**，按芯片选择 `AppleSilicon` 或 `Intel` 安装包。

| 使用方式 | 需要安装 |
| --- | --- |
| 仅自定义遥控器按键 | 本应用 |
| 微信语音输入 | 本应用、[微信输入法 Mac 版](https://z.weixin.qq.com/)、[BlackHole 2ch](https://github.com/ExistentialAudio/BlackHole#installation-instructions) |
| macOS 本机语音识别 | 本应用；系统需支持本机中文识别并已准备相应语言资源 |

- macOS 14 或更高版本；遥控器为 `IPRC1000`（VID/PID `0A5C:8502`）。目前要求系统中只有一只同名已配对遥控器。
- **无需安装 PacketLogger、Xcode 附加工具或蓝牙日志描述文件。** 微信流式组件已随应用提供。
- 语音已在 Apple Silicon / macOS 26.6.2 实测。Intel 包通过构建和软件自测，蓝牙语音仍需 Intel 实机验证。

## 安装

1. 打开 DMG，将 `IPRC1000 Adapter.app` 拖入“应用程序”。更新时先退出旧版，再覆盖安装。
2. 启动应用。若 macOS 提示无法验证开发者，在“系统设置 → 隐私与安全性”中允许打开。本发布包使用 ad-hoc 签名，尚未公证；请从本仓库下载，校验文件随 Release 提供。
3. 按提示在“隐私与安全性”中开启本应用的**输入监控**和**辅助功能**。更改权限后如未生效，退出应用再打开。
4. 在 macOS 蓝牙设置中配对 `IPRC1000`。关闭应用窗口不会退出，应用会留在菜单栏。

## 自定义按键

1. 打开“连接诊断”，点击 **启用独占按键适配**，完成 macOS 管理员认证。
2. 按一下遥控器按键使设备上线。
3. 打开“按键映射”，选择按键，设置单键、修饰键组合、媒体键或“不执行”，然后保存。

![按键映射](docs/images/key-mapping.jpg)

支持多组映射、切换、重命名及导入导出；遥控器底部方块键用于循环切换配置组。接管只针对这只遥控器，不拦截其他键盘。

## 在光标处语音输入

### 微信输入法

1. 安装微信输入法和 **BlackHole 2ch**，在系统中启用微信输入法。
2. 在微信输入法设置中开启 **Fn 长按语音输入**，麦克风选择 **自动检测**。
3. 在适配器“连接诊断”里选择 **外部语音输入法（微信等）**，点击 **启用蓝牙语音输入**，完成管理员认证。该按钮同时启用光标输入，不需要点击调试或测试按钮。
4. 点击任意普通文本输入框，按住遥控器麦克风说话，松开结束。无需停留在适配器窗口。

适配器会在说话时临时切换输入源和麦克风，将遥控器声音送给微信，结束后恢复。保持系统扬声器为正常输出，**不要把扬声器也改成 BlackHole**。微信模式的识别和联网行为由微信输入法负责。

### macOS 本机识别

选择 **macOS 本机识别 → 光标输入**，再点击 **启用蓝牙语音输入**并允许语音识别权限。按住遥控器说话，松开后将识别结果写入本次说话时的输入框。本模式使用本机中文识别；语言资源不可用时会提示，不自动改用云端识别。

### 停止与恢复

- **停止语音**：关闭音频并恢复临时配置，按键接管继续工作。
- **停用输入**：停止文字识别或输入法会话。
- **停止接管**或退出应用：同时结束按键和语音功能。
- 正常语音启用后持续运行，不会五分钟自动停止。遥控器休眠时显示等待连接，唤醒后继续接管。
- 重新启动接管仍可能要求管理员认证，无需反复安装描述文件。

## 常见问题

**原始字母直接输出或按键未映射**：检查“输入监控”“辅助功能”权限，并确认已点击“启用独占按键适配”或“启用蓝牙语音输入”。“停止接管”后原始行为会恢复。

**微信没有浮窗或没有文字**：确认微信 Fn 长按语音已开启、麦克风为自动检测、BlackHole 为 2ch 版本；在适配器重新启用语音，再点回目标输入框。更换识别方式或快捷键后也需重新启用。

**冷唤醒有等待**：无需先按方向键，但设备建立蓝牙连接仍需时间。应用会保留启动期间已收到的音频；连接建立前未传到 Mac 的声音无法补回。

## 权限与隐私

语音启用期间，应用会临时开启 macOS 蓝牙诊断入口。底层包含本机蓝牙流量，程序仅解析目标遥控器音频，不保存原始抓包或录音；保留正常系统认证，不安装常驻服务。停止语音或正常退出后恢复配置。若应用和独立清理进程同时被强杀或系统崩溃，可能需下次启用时恢复。
