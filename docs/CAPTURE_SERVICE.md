# 当前接管与音频权限

v0.3.1 使用应用自身的临时管理员进程接管唯一配对的 IPRC1000，按键通过目标专属 IOHID 独占读取；无全局键盘钩子，不等待其他键盘事件。

语音通过原生 XPC 客户端连接系统蓝牙捕获服务，不运行 PacketLogger 或其框架。启用语音时，通过 CFPreferences 临时设置 HCITraces，并保留正常认证、关闭文件抓包；严格按目标地址、handle、Interrupt CID、方向和 F7 格式筛选。底层是本机 HCI 流，不能称为单设备底层采集。

独立配置进程持有恢复快照与控制管道。正常停止先关闭 XPC 接收，再恢复配置；停止语音保留键盘。前台退出使管理员进程清理音频、配置和目标独占。拥有者死亡的 EOF 也会触发配置恢复；所有相关进程同时被强杀或整机崩溃时，恢复依赖下次启动租约，不提供无条件保证。

管理员认证与输入监控是独立权限。当前仍使用临时提权兼容接口，重新启动可能要求认证；不安装免认证服务，不改系统授权数据库，不需要开发者付费会员或三天更新的描述文件。

用户操作见 [README](../README.md)，代码结构见 [实现说明](VOICE_IMPLEMENTATION.md)，构建与回归见 [开发说明](DEVELOPMENT.md)。历史日期文档只记录对应版本的实验结果，不作为当前安装步骤。
