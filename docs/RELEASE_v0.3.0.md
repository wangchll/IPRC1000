# v0.3.0 — 遥控器语音与光标输入

构建号：`20261103.34`。最低系统：macOS 14。提供 Apple Silicon / Intel 独立 DMG；发布包使用 ad-hoc 签名，未公证。更新保留现有按键配置。

## 更新内容

- 目标遥控器单设备 IOHID 独占接管，无全局键盘钩子；拦截原始 M/I 并按配置转发按键。
- 冷重连时恢复缓存中仍按住的麦克风，避免需要补按才能启动。
- 接收已确认的 Classic F7 Int16LE PCM，支持 macOS 本机中文识别后写入光标。
- 参考 VibeStick 实现微信 Fn 长按与 BlackHole 实时送音，排空后释放 Fn、恢复麦克风/输入源；支持快速连续两句。
- 音频重试不释放键盘接管；非阻塞输出暂满时保留按键重试。
- 修复 HID rollover 误松键、本机识别最终结果竞态、粘贴顺序、修饰键释放和快捷键切换状态。
- ARM/Intel 捆绑组件均明确支持 macOS 14；补齐 Intel 微信组件、许可证与测试页。

## 安装与依赖

1. 下载对应架构 DMG 和同名 `.sha256`，核对校验值后把应用拖到“应用程序”。
2. 本版无 Developer ID / Apple 公证；按 README 的首次打开指引处理系统提示，检查输入监控和辅助功能权限。
3. 语音需要 Apple 官方 PacketLogger（安装到 `/Applications/PacketLogger.app`）、当前有效的蓝牙日志环境和 BlackHole 2ch；这些第三方组件不包含在本安装包内。
4. 微信模式需本机已启用微信输入法、配置 Fn 长按语音、麦克风设为“自动检测”。macOS 本机模式需要中文离线识别模型与语音识别授权。
5. 启动临时蓝牙语音并完成管理员认证，选识别方式、启用光标输入，再点入目标应用输入框按住遥控器说话。

## 验证与边界

- `.33` 已完成真实冷唤醒一次按住、微信光标写入、半秒间隔连续两句、M/I零漏出以及Fn/麦克风恢复验证。
- 本版 `.34` 的 review 修复通过 Release、自测、ASan/UBSan和双架构/双签名检查；新修复没有重新完成实物整套验收。
- Intel 软件自测在Rosetta执行，不能替代Intel真机蓝牙/权限/微信验证。
- PacketLogger底层读取本机HCI流，临时管理员进程只解析目标F7；无全局键盘监听，不保存原始抓包。
- 启动临时捕获仍可能要求管理员认证；免重复认证服务尚未安装或启用。当前提权接口已弃用，可能受未来系统变更影响。
- 首次音频组件初始化曾耗时约2.1秒；后续冷重连从设备枚举到Fn约0.18秒，不保证所有环境相同。
