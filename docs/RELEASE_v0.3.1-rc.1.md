# v0.3.1-rc.1：按键接管与语音依赖拆分测试版

构建：20261103.35。用于验证另一台Mac上未安装PacketLogger时的基本按键接管，不替换v0.3.0正式最新版。

- 新增“启用独占按键适配”：仅目标IOHID键盘接管，无需PacketLogger/蓝牙日志描述文件/BlackHole，仍需输入监控、辅助功能及启动时的临时管理员认证。
- “启动临时蓝牙语音”单独开启Apple音频工具；“停止语音”保留键盘，“停止接管”才结束管理员进程。
- 语音接收仍依赖官方PacketLogger，不是无工具语音实现。缺工具不再把整个按键接管挡死。
- 缺失工具、签名失败、不可执行、通信失败、取消认证分别显示可操作提示。
- 普通键盘服务匹配失败的文案改为已识别目标、映射未就绪，避免误导为设备地址写死。
- 不增加全局键盘监听，不改变目标VID/PID、配对地址或其他设备输入处理范围。

验证：Release及内置自测；直接包含生产启动代码的无PacketLogger模拟回归，ASan/UBSan通过。
这是启动依赖回归，不代表另一台Mac真实独占已验收；此测试版需要目标M2 Mac实际验证。

测试步骤：退出旧版，把对应架构App替换到“应用程序”，从“应用程序”启动；如系统要求，重新授予输入监控/辅助功能。
打开“连接诊断”，点击“启用独占按键适配”并认证，按一次方向键核对接管状态和映射。
先不启动语音、不安装PacketLogger。确认按键后再核对M/I隔离。
