# IPRC1000 Adapter v0.3.1

本版将蓝牙语音改为应用内原生接收：**不再需要 PacketLogger、Xcode 附加工具或蓝牙日志描述文件**。启用后持续运行至主动停止，按键与语音可独立启停。

## 更新内容

- 支持遥控器语音通过微信输入法或 macOS 本机中文识别写入光标。
- 修复冷唤醒首音丢失，保留启动音频并按20ms小块流式转发。
- 改善连续输入，增加有界发送、取消、组件超时和麦克风恢复。
- 仅接管目标遥控器按键；停止语音保留按键接管。
- 精简安装与使用文档，正式版隐藏五分钟开发测试入口。

## 下载与开始使用

1. Apple Silicon 下载 `IPRC1000-Adapter-0.3.1-AppleSilicon-GitHub-AdHoc.dmg`，Intel 下载对应 `Intel` 包；校验值见 `SHA256SUMS.txt`。
2. 将应用拖入“应用程序”，配对 IPRC1000，授予输入监控与辅助功能权限。
3. 微信模式另需微信输入法和 **BlackHole 2ch**：微信设为 **Fn长按语音**、麦克风 **自动检测**；在适配器选择识别方式并点击 **启用蓝牙语音输入**，完成系统认证，然后点入文本框，按住遥控器说话。

仅使用自定义按键不需 BlackHole 或微信输入法。macOS 本机模式需可用的本机中文识别资源。完整步骤和官方下载入口见 [README](https://github.com/wangchll/IPRC1000#readme)。

## 系统与权限

macOS 14+。正常启动仍可能要求管理员认证，不安装常驻服务。语音启用期间临时开启本机蓝牙诊断，程序仅解析目标遥控器音频，关闭文件抓包；停止或正常退出后恢复。异常恢复边界见 README。

发布包为 ad-hoc 签名，尚未公证。Apple Silicon 本机已完成真实微信输入、冷唤醒首词和持续会话验证；两种架构均通过构建、签名与软件自测，Intel 蓝牙语音、其他Mac及整机睡眠/全天稳定性仍待实机验证。
